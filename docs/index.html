gamma-factorial

Generalized factorial calculator

n! = Γ(n+1), extended to any real number via the Lanczos approximation — not just non-negative integers. Every result comes with a live curve of the function around it, so you can see the interpolation, not just read a number. Runs entirely in this page; no server, no install.
