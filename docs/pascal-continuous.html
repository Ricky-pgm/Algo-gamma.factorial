gamma-factorial

Pascal's triangle, made continuous

The classic binomial coefficient C(n, k) only exists at whole numbers. Replacing factorials with the Gamma function extends it into a smooth curve that still passes exactly through every value of Pascal's triangle — and also makes sense between the whole numbers.

Try it locally

This module is part of the gamma-factorial package:

from gamma_factorial import binomial

binomial(5, 2)      # 10.0
binomial(4.5, 2)    # 7.875
binomial(0.5, 0.5)  # 1.0

Every point on the curve above is computed by this same function, run in Python and then frozen into data for this page.
