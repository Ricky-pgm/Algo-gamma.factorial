Pascal's triangle, made continuous

The classic binomial coefficient C(n, k) only exists at integer points. By replacing factorials with the Gamma function — C(n,k) = Γ(n+1) / (Γ(k+1)Γ(n-k+1)) — the same formula extends into a smooth curve that passes exactly through every value of Pascal's triangle, and also makes sense between the integers.

Try it locally

This module is part of the gamma-factorial package:

from gamma_factorial import binomial

binomial(5, 2)      # 10.0            — classic coefficient
binomial(4.5, 2)    # 7.875           — continuous interpolation
binomial(0.5, 0.5)  # 1.0

Every point on the curve above is computed by this same function, run in Python and then frozen into data for this page.

C(n, k) = Γ(n+1) / (Γ(k+1)·Γ(n−k+1)), computed via the Lanczos approximation of the Gamma function. At integer points 0 ≤ k ≤ n, it matches classic Pascal's triangle exactly.
